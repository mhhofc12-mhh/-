# কুরআন শিখতেই হবে

**Quran Reading + Arabic Learning + Tajweed + Word-by-Word Meaning**

এই Android app-এর লক্ষ্য: যারা আরবি জানেন না, তাদের ধাপে ধাপে কুরআন শুদ্ধভাবে পড়তে শেখানো এবং কুরআনের আরবি শব্দের অর্থ বুঝতে সাহায্য করা।

## Version 1
- Clean, ad-free UI
- Offline-first learning structure
- Quran section with Surah → Ayah navigation
- Arabic text, Bangla pronunciation, full meaning
- Word-by-word meaning
- Arabic alphabet lessons
- Arabic vocabulary
- Tajweed lessons
- Arabic grammar
- Audio practice placeholder UI
- Quiz
- Progress
- Bookmark
- Settings

> Quran text, translation, transliteration, tajweed rules and audio should be reviewed against trusted/qualified sources before production release.

## Build
Open this folder in Android Studio and let Gradle sync. Run the `app` configuration on an Android device/emulator.

## Ads
Ads are intentionally excluded from Version 1.
