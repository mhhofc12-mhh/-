# Roadmap

## Phase 1 — UI/Foundation
- Home cards and navigation
- Quran/Surah/Ayah screens
- Arabic learning lessons
- Tajweed/Vocabulary/Grammar/Quiz screens
- No ads

## Phase 2 — Real Offline Content

- Local Room database
- Offline audio

## Phase 3 — Learning Engine
- Lesson completion
- Streak
- XP
- Quiz scoring
- Bookmark/Notes
- Search

## Phase 4 — Optional Online Sync
- Account
- Cloud backup
- Content updates
- Audio updates

## Important
Before publishing, Quran text, translation, transliteration, tajweed content and audio must be checked with reliable sources/qualified reviewers.
